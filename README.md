تطبيق يوفر لك أسعار الدولار مقابل الدينار العراقي في أغلب محافظات العراق واقليم كوردستان، وكذلك أسعار العملات العالمية مقارنةً بالدينار العراقي، محدثة كل دقيقة.

---

## مميزات التطبيق

- ✓ التطبيق مجاني مدى الحياة
- ✓ التطبيق خالٍ من الإعلانات مدى الحياة
- ✓ التطبيق غير ربحي مدى الحياة
- ✓ التطبيق لا يحتاج إلى أي أذونات
- ✓ التطبيق خالٍ من التنبيهات المزعجة
- ✓ التطبيق خفيف جداً وسريع
- ✓ التطبيق لا يجمع بياناتك الخاصة

## حقوق الاستخدام

- لا توجد حقوق نشر أو قيود على التوزيع
- يمكنك استخدام التطبيق بأي شكل من الأشكال

## توضيح هام

أسعار العملات هي لغرض الاطلاع والمعرفة فقط، وأن التطبيق لا يتحمل مسؤولية القرار المالي للمستخدم أثناء التداول أو الصرف.

يوجد تطبيق مصغر (ويدجت) يمكنك إضافته من الشاشة الرئيسية في هاتفك لتظهر لك أسعار البورصة المفضلة لك، مع تحديث تلقائي كل ساعة وزر تحديث فوري.

**دليل الألوان:**

| اللون | المعنى |
|---|---|
| 🔴 أحمر | هبوط السعر |
| 🟢 أخضر | صعود السعر |
| ⚪ رصاصي | السعر مستقر أو لا يتوفر تحديث حالياً |

## طريقة البناء

1. ثبت **Android Studio**: https://developer.android.com/studio
2. Open → اختر مجلد `CurrencyApp`
3. انتظر Gradle Sync يخلص (إذا طلعت مشكلة "Incompatible Gradle JVM version"، غيّر الـ JDK المستخدم لـ 17 من Project Structure → SDK Location)
4. لتصدير نسخة موقّعة: **Build → Generate Signed Bundle / APK**، واستخدم ملف `keystore.properties` (راجع `keystore.properties.template`) حتى يصير التوقيع تلقائي بدون إعادة إدخال بياناته كل مرة
